# TDD / XP
- Work in small batches.
- Find the tiniest commit you can push in production ASAP.
- Commit atomically.
- For new behaviour, write the failing test before production code. 
- For refactoring, stay green and preserve behaviour.
- Run the relevant tests and static analysis before and after each batch, and fix anything you broke before continuing.

# Clean code
Whenever you write or refactor code, load the `micro-design` skill.
